# Générateur de mot de passe

## Description

Programme Python permettant de générer des mots de passe personnalisés et aléatoires. L'utilisateur choisit les éléments composant son mot de passe.

## Fonctionnement

L'utilisateur choisit la longueur de son mot de passe, s'il contient des majuscules, des chiffres et des caractères. Le mot de passe est alors généré aléatoirement en fonction des critères choisi par l'utilisateur.

## Concepts utilisés

- Conditions
- Boucles
- Chaines de caractères
- Bibliothèque Python

## Objectifs du projet

- Manipuler le module random
- Manipuler différentes catégories de caractères
- Développer un programme utile
